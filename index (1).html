🗄️ Step 1 — Connect Google Sheets (Subscriber Database)

This saves every subscriber directly into a Google Sheet. You and Ugochi can open it on any phone and see everyone who submitted the scorecard — live.
  1. Open Google Sheets → create a new sheet → name the first sheet tab Subscribers
  2. In Row 1 add these headers exactly: name | email | score | tierTitle | date
  3. Go to Extensions → Apps Script
  4. Delete everything there and paste the script Wisdom gave you → click Save
  5. Click Deploy → New Deployment → Web App
  6. Set Execute as: Me · Set Who has access: Anyone → Deploy
  7. Copy the Web App URL and paste below → Save ✅
✅ Connected! Subscribers will now save to your Google Sheet.
